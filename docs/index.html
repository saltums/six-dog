使い方
● 閲覧
  • 見たい年を選んでカレンダーへ。日付をタップすると公演の詳細が見られます
  • 𝕏やLINEで公演ページをシェアできます
  • 🔥アツかった / 🥹エモい ボタンで、昔を思い出しながらその公演への反応をタップで表現できます
● 投稿
  • 不足している情報は投稿、誤っている情報は修正ができます
  • ログイン不要、誰でも気軽にどうぞ
● 分析
  • どのアーティストが多く出演したか、どの年に公演が多かったかなどがBIダッシュボードで分かります
・データは有志による調査・復元のため、一部推定を含みます
